# Before you click Merge

- [ ] Every "Done means" line has pasted proof (command output or screenshot), not a claim.
- [ ] Nothing invented: every name, number, date and claim is in `content.md`.
- [ ] No file outside the ticket changed, including `AGENTS.md`, `content.md`, `checks/` and `.github/`.
- [ ] No check was weakened: no new excludes, skips, `continue-on-error`, or a changed checker hash.
- [ ] Nothing new is loaded or installed (scripts, fonts, packages, outside URLs).
- [ ] No silent decision: anything it chose that you didn't ask for is named in its message.
- [ ] CI is green on GitHub, not only on the board.
- [ ] You opened the result yourself: clicked the links, looked at it on a phone width.

All yes: merge on GitHub (leave a Comment review if you're the PR's author). One no: send it back (see `SEND-BACK.md`).
